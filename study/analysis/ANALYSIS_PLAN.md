# Analysis plan, Rev 6 (written before any Rev 6 analysis is run)

Branch `rev6-reanalysis`, from the Rev 5 head (`d901c1f`). Status: **approved with amendments (this version)**. The amendments below were decided before any Rev 6 analysis was run. No analysis in Tasks B to J had been started when this amendment was committed. Nothing here changes the manuscript. Every number quoted below is read from a result file named next to it; anything else is marked *to be computed*.

## 0. Ground rules that apply to every analysis

- **Seed.** Base seed 20260924. Each procedure gets its own generator, `np.random.default_rng([20260924, crc32(contrast_id)])`, where `contrast_id` is the ID in the grid manifest (section 3). 1,000 resamples unless stated.
- **Manifest first.** Before Task B runs, the code writes `study/analysis/grid_manifest.csv` (one row per contrast in section 3). `RESULTS_REPORT.md` must match the manifest row for row; a contrast that cannot be run stays in the table with the reason.
- **Thresholds are fixed here.** If a threshold proves ill-posed, the original result stays, the problem is recorded, and a labelled post-hoc analysis is added beside it.
- **Failed designs are results.** A design that cannot be fitted, or fails balance (|SMD| >= 0.1), is reported as such and is not re-tuned.
- **Output.** Scripts in `study/scripts/analysis/`, small results in `study/analysis/results/*.json`, reports in `study/analysis/`. Large downloaded data goes to `study/analysis/data_private/` (git-ignored). No references are added, no manuscript file is edited.

## 1. Existing data and definitions (read from the repo; carried over unchanged unless a task says otherwise)

- Site table: `processed_data/epsd/release/mammalian_sites.parquet` (1,768,068 rows; source set B evidence; columns `DAS`, `study_cluster_count`, `tier`, `disorder`, `kinase_match`, `conserved`). Human-only file with domain overlap: `human_sites_source_set_a.parquet` (1,071,725 rows; source set A evidence; `in_domain`). Sequence-motif indicator: `kinase_motif_sequence.parquet`.
- Tier rule (study-cluster rule): GOLD if DAS >= 2 or study-cluster depth >= 10; SILVER if DAS >= 1 or depth 3 to 9; BRONZE otherwise. Comparisons are GOLD vs BRONZE only.
- Protein-level indices in `sei_protein.parquet`: primary = log10(1 + distinct PMIDs linked to the protein's gene IDs in gene2pubmed); secondary = log10(1 + study clusters among the protein's sites). Secondary is descriptive only from Rev 6 on.
- Estimators as implemented in phosnet: coarsened exact matching (CEM) with strata = species x residue type x index decile and weights that reweight BRONZE to each stratum's GOLD count; propensity matching 1:1 within a caliper of 0.2 SD of the logit. Estimands: odds ratio (domain overlap), difference in proportions (conservation, motif), difference in means (disorder).
- **Change from Rev 5 (D1, approved).** Rev 5 tested domain overlap on the source-set-A human file (tier from set A evidence) and the other three signals on the set-B file, so "GOLD" was not the same set of human sites in the two analyses. Rev 6 uses **set-B tiers for every signal**, including human domain overlap (set-B tier merged onto the human file on `epsd_id`). **The Rev 5 domain-overlap numbers used set-A tiers and will change for that reason**; the set-A result is kept as a labelled comparison row.
- **Study-cluster rule (fixed before Task B).** Primary rule = the rule that produced the Rev 5 tiers: a PMID is a candidate when it is linked to at least **884** sites, and candidates merge when the Jaccard similarity of their site sets is at least 0.90 (union-find). Traced in `audit_reports/phase1_mammalian_ingest_report.md`: 884 = round(0.0005 x 1,768,068), the 500-site cutoff of an earlier human-only stage (500 / 1,071,725, about 0.047%) restated as 0.05% of the pooled site count. It is a proportional rule chosen to keep the earlier rate, not a value derived from a data-quality criterion. Sensitivities: **500** (the code default, and the value used for the secondary index) and **1,000**. Under each, cluster identities, per-site depth and tiers are recomputed (block G13). RECONCILIATION.md states this trace or says plainly where it cannot be traced.
- **Lead for Task B, not yet confirmed.** In `earlier_results/matching_results.json` the text quotes `unmatched_all_sites` (includes sites of proteins with no primary index) and Table 1 quotes `unmatched_mapped_sites` (only sites with an index). For disorder those are 0.0310 and 0.0438, matching the mismatch you found. Task B confirms this for every row and does not assume it.

## 2. Decision rules (defaults from the brief, applied to every contrast unless a row says otherwise)

| Rule | Definition |
|---|---|
| **Survives adjustment** | In the primary design (CEM on the primary index, Task C), the protein-cluster bootstrap 95% CI excludes the null (0 for differences, 1 for odds ratios). |
| **Attenuation** | (crude - adjusted) / crude, with crude and adjusted computed on the same records in the same resample. For odds ratios, computed on the log scale: (log crude - log adjusted) / log crude. Reported with a percentile bootstrap 95% CI. |
| **Largely explained by study effort** | Point estimate of attenuation >= 50%. A negative attenuation (adjustment increases the estimate) is reported as "not attenuated". If the crude estimate's CI includes the null, attenuation is reported but not interpreted. |
| **Predictor gap (finding 5)** | Two one-sided tests, margin +/-0.05, on the top-three minus bottom-three decile AUROC gap, at alpha = 0.05 each; equivalent to the 90% bootstrap CI lying inside (-0.05, +0.05). "Gap absent" only if equivalence holds; otherwise "not detectable" (CI includes the margin) or "gap present" (CI excludes zero and lies outside the margin). |
| **Established measures (Task H)** | Same "survives" rule. |
| **Decisions changed (Task F)** | A sensitivity analysis "changes" a conclusion if it moves a contrast across the survives/not or the largely-explained/not boundary relative to the primary design. The count of changed decisions is reported per analysis. |
| **Multiplicity** | None applied; all contrasts are reported and decisions rest on pre-set intervals. This is stated in the results file. |

## 4. Task B: reconcile and redo inference

1. **Reconciliation.** For every Table 1 and text estimate, record source set, species set, tier rule and record set (all sites vs sites of mapped proteins) and reproduce both numbers from code. Output `RECONCILIATION.md`. The 7.4% vs 12.3% ortholog coverage (conserved indicator defined for X% of which denominator?) and 1,113 vs 1,070 study clusters (all clusters vs clusters with resolved years?) are recomputed from the site table and the cluster assignments, with both denominators printed.
2. **Study clusters.** Document the merge rule as implemented (`build_sei_secondary_table`: a PMID linked to at least 884 sites in the dataset is a candidate; two candidates merge when the Jaccard similarity of their site sets is at least 0.90; merges are transitive). Report how many PMIDs were candidates, how many formed multi-PMID clusters, cluster size distribution, and how the 884 value arose (from the code and its call arguments; the code default is 500 and the 884 must be traced, not assumed).
3. **Protein-cluster bootstrap.** Population: the analysis records of a contrast. Resampling unit: protein (`uniprot_id`), with replacement, keeping all its sites; 1,000 resamples. **The whole pipeline is re-run inside each resample** (index deciles, strata, weights, estimate), so the CI includes matching variability. CI: percentile 95%. For propensity matching the model is refitted in each resample; the fallback of decision D7 applies (200 resamples only if one contrast's full bootstrap is projected to exceed 2 hours). The stratified bootstrap of Rev 5 is superseded.
4. **Two-way sensitivity.** Assign each site a primary study cluster (the cluster containing the largest number of its PMIDs; ties to the cluster with the most sites). Compute the protein-cluster variance V_p, the study-cluster variance V_s, and the protein x study intersection-cell variance V_ps, each by bootstrap, and combine as V = V_p + V_s - V_ps (Cameron-Gelbach-Miller form) for a normal-approximation CI. If V <= 0 or the intersection cells are essentially singletons, the analysis is recorded as not feasible with the reason. Applied to G1 D1 only.
5. **Tests on indices.** The Kruskal-Wallis, Spearman and point-biserial tests in Rev 5 already use one value per protein, so the unit is protein already. They are still not independent because proteins share studies, and with about 87,000 proteins a p-value carries no information beyond the effect size. Rev 6 **drops these p-values** and reports the effect sizes (rank-biserial r, Spearman rho, point-biserial r) with protein-bootstrap CIs. This replaces the Benjamini-Hochberg block.

## 6. Task D: harden the primary index

1. **Bulk-link correction.** From `gene2pubmed` (cached copy dated by its sidecar file), count genes per PMID. Variant V50 excludes PMIDs linked to more than 50 genes when counting a gene's PMIDs; V20 and V100 are the sensitivity thresholds. Recompute log10(1 + n) per protein as before. **V50 is the primary index for Rev 6** (decision D2); the original index is reported beside it in every table. Report the Spearman correlation of each variant with the original index and the number of PMIDs and gene links removed.
2. **Time normalisation.** Variant VT: log10(1 + n / t), where n is the (bulk-corrected, V50) count of a gene's PMIDs and t = max(1, 2025 - y0 + 1) (2026 in the sensitivity), with y0 the earliest resolved publication year among the gene's PMIDs (years from `pmid_year.parquet`; PMIDs without a resolved year are counted in n but do not set y0; genes with no resolved year are excluded from VT and counted). The primary reference year is **2025** (last complete year); 2026 is a sensitivity (decision D5).
3. **Pharos/TCRD Target Development Level.** Download the target list with TDL and UniProt IDs. Report the index (original and each variant) by TDL (Tclin, Tchem, Tbio, Tdark), and the AUROC for separating Tdark from all other proteins (index as the score, protein-bootstrap CI). Note in the report that TDL is built from more than publication counts (for example annotation, ligand and antibody data), so agreement is supportive, not a calibration.
4. **GO check.** Number of distinct GO terms per protein from the GOA human annotation file (versions and evidence-code handling recorded; all evidence codes counted, with a sensitivity that excludes IEA); Spearman correlation with each index variant.
5. **Choice of variant for the main comparisons.** Primary index for Rev 6 = V50 (decision D2), fixed before any result. The comparison variants are the original index, V20, V100 and VT. If the Tdark AUROC and the GO correlation rank the same variant first (higher = better supported), and it is not V50, report G1 with both V50 and that variant and state both. If they disagree, report all variants and choose none. G4 reruns S1 to S4 under D3 for each variant and reports whether any decision changes (section 2).

## 10. Task I: within-protein selection (G10)

- **Population.** PSP sites (human) that are LT-supported or MS-only, joined to the site table (as in Task H), in proteins that have at least one site of each kind and where the outcome varies within the protein.
- **Exposure.** LT-supported (1) vs MS-only (0). **Outcomes.** Conservation, domain overlap, motif (binary) and disorder (continuous).
- **Estimator.** Binary outcomes: conditional logistic regression with a fixed effect per protein, adjusted for residue type. Disorder: linear regression with protein fixed effects (within estimator) adjusted for residue type. The primary index is not needed because the comparison is within protein.
- **CI.** Protein-cluster bootstrap, 1,000 resamples (the resampling unit is the protein, so the fixed effects are refitted). If the conditional-logit bootstrap is projected to exceed 2 hours per contrast, 200 resamples are used (decision D7) and stated beside the result.
- **Rule.** "Survives": the CI excludes the null.

## 13. Decisions (approved, with the changes shown)

- **D1. Tier definition.** Approved. Set-B tiers for every signal; human domain overlap uses set-B tiers. Rev 5 domain-overlap numbers used set-A tiers and will change for that reason. **Addition:** set B's agreement component is not independent, because dbPTM re-collects PhosphoSitePlus and Phospho.ELM. A sensitivity **depth-only tier rule** is run on the main matched comparisons (block G12): GOLD = study-cluster depth >= 10, SILVER = depth 3 to 9, BRONZE = depth <= 2, with no agreement component.
- **D2. Primary index.** Approved. The bulk-corrected index (PMIDs linked to more than 50 genes excluded, V50) is primary. The original index is a comparison; V20 and V100 are sensitivities. **This is a change from Rev 5 and was decided before any Rev 6 result.**
- **D3. PhosphoSitePlus evidence categories (changed).** Categories follow Kalyuzhnyy et al. 2022, counting n = `LT_LIT` + `MS_LIT` + `MS_CST`: high = n >= 5, medium = n = 2 to 4, low = n = 1. Low-throughput-supported = `LT_LIT` >= 1; MS-only = `LT_LIT` = 0 and `MS_LIT` + `MS_CST` >= 1. If the column semantics in the downloaded file version differ from this, the task stops and is reported. Contrasts: high vs low; LT-supported vs MS-only.
- **D4. Inference.** Approved. The protein-cluster bootstrap is primary for all tables (including the predictor gaps). The two-way (protein and study cluster) analysis is the sensitivity.
- **D5. Reference year for time normalisation (changed).** 2025 (last complete year) is primary; 2026 is a sensitivity.
- **D6. Annotated-only domain analysis.** Approved as a diagnostic only, because it conditions on a variable derived from the outcome.
- **D7. Bootstrap limits.** Primary CEM results always use 1,000 resamples. The 200-resample fallback applies **only** to propensity matching and the conditional-logit bootstrap, and **only** if a single bootstrap run for one contrast is projected to exceed 2 hours (projection from the timing of the first resamples, logged). The resample count is stated beside each affected result.
- **P-values on indices.** Dropped, as proposed; effect sizes with protein-bootstrap CIs are reported.
