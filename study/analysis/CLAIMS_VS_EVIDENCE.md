# Claims versus evidence, Rev 6 (internal working file, not part of the manuscript)

Written by `scripts/analysis/build_claims.py` from the files in `study/analysis/results/` and, for the Rev 5 values, `study/earlier_results/*.json`. Every number is read from a result file. Nothing in the manuscript folder is read for numbers or edited. Intervals are 95% intervals; the gene-cluster bootstrap is the primary interval from the amendment of 2026-10-01 unless the row says otherwise. Block and contrast identifiers refer to `grid_manifest.csv` and `results/manifest_status.csv`.

## Grading rules (fixed before the grades were computed; applied by the script)

**Effect claims about a signal (GOLD minus BRONZE, adjusted for the primary index, CEM, V50, set-B tiers).** Checks: K1 the gene-cluster interval of the primary estimate (G17) excludes the null. K2 the adjusted estimate lies on the same side of the null in every population where the signal is defined (G1, G2, G3 and P-abund in human, mouse and rat under D1, D4, D5). K3 robustness checks, each counted as a failure if its estimate has the opposite sign to the primary estimate or its gene-cluster interval includes the null: canonical reviewed accessions (G16), alternative tier definitions (G19), residue strata (G6), leave-one-cluster-out (G7), tier thresholds (G8), matcher D2b (G18, decision-bearing contrasts) and index variants (G4). K4 the two-way interval (B4; G1 D1 only) excludes the null (a failure if it does not). K5 the within-gene comparison (G21, model M1, P-all) persists (a failure if it does not; ignored while not run). F = number of K3 failures + K4 failure + K5 failure.

**Grade:** *not supported* if K1 fails; otherwise *weak* if K2 fails or F >= 3; *moderate* if F is 1 or 2; *strong* if F = 0. **Construct caveat:** where the plan records a design-level limitation that bears directly on what the claim would mean, the grade is lowered one step and the caveat is named in the row (conservation only: limitation 9). **Not graded:** the database-lookup kinase-motif indicator (S5) is descriptive only (circular: the indicator comes from the annotation tables that also feed the tiers); it has no grade in any row. **Other claims:** a deterministic count or description read from a result file is *strong*; a claim that goes beyond what the design identifies (mechanism, cause) is *not supported*; predictor claims follow the rule given in section 6.
